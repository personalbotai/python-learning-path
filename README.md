## ✨ Features

- 💻 **In-Browser Code Execution:** Run Python code interactively without installing anything locally.
- 📖 **55 Curated Lessons:** Comprehensive roadmap from language syntax to advanced concepts and data science foundations.
- 🎯 **Interactive Exercises & Quizzes:** Immediate feedback and solution validation for every topic.
- 📊 **Progress Tracking:** Automatic state synchronization via `localStorage` to keep track of completed lessons.
- 🎨 **Modern Dark UI:** Responsive mobile-first design with syntax highlighting and quick search.
- ⚡ **Zero-Build Architecture:** Pure client-side application hosted on GitHub Pages.

## 📚 Curriculum Overview

1. **Python Foundations** — Variables, primitive types, operators, dynamic typing.
2. **Control Flow** — Conditionals, match-case, while & for loops, iterators.
3. **Data Structures** — Lists, tuples, dictionaries, sets, comprehensions.
4. **Functions & Modularization** — Scope, `*args`/`**kwargs`, lambda, closures, decorators.
5. **Object-Oriented Programming** — Classes, inheritance, polymorphism, dunder methods, dataclasses.
6. **Error Handling & Files** — `try-except-finally`, custom exceptions, file I/O, context managers.
7. **Modern Standard Library** — `math`, `datetime`, `collections`, `itertools`, `pathlib`, `json`.
8. **Advanced Concepts** — Generators, async/await, type hinting, virtual environments & `pip`.

## 🛠️ Local Development

Clone and run locally with any static file server:

```bash
git clone https://github.com/personalbotai/python-learning-path.git
cd python-learning-path
python3 -m http.server 8080
```

Open `http://localhost:8080` in your web browser.
